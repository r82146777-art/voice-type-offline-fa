# تایپ صوتی آفلاین فارسی (نسخه اصلاح‌شده)

## تغییرات اعمال‌شده

1. **چینش کلیدهای فارسی (RTL)**  
   ترتیب کلیدهای شیفت و حذف در ردیف سوم اصلاح شد تا شبیه کیبوردهای استاندارد فارسی (مثل Gboard) باشد. در حالت راست‌چین، شیفت سمت راست و حذف سمت چپ قرار می‌گیرد.

2. **افزایش اندازه صفحه‌کلید**  
   ارتفاع ردیف کلیدها از ۴۸dp به ۵۶dp افزایش یافت. نوار ابزار و اندازه فونت کلیدها نیز کمی بزرگ‌تر شد.

3. **نام در بخش درباره ما**  
   نام **رضا ایمانزاده** به عنوان یکی از مدیران اضافه شد:
   - مدیریت: امیرحسین بابایی، رضا ایمانزاده

4. **رفع مشکل مجوز میکروفون**  
   درخواست مجوز میکروفون در همان شروع برنامه (onCreate) انجام می‌شود تا هنگام فعال‌سازی صفحه‌کلید یا استفاده از دیکته، خطای «دریافت مجوز» کمتر رخ دهد. پیام راهنما نیز بهبود یافت.

## ساخت APK

```bash
# نیاز به Android SDK (platform 34) و JDK 17
export ANDROID_HOME=/path/to/sdk
cd VoiceTypeFa
# فایل model-fa.zip (حدود ۵۳ مگابایت) را از سورس اصلی در مسیر زیر قرار دهید:
# app/src/main/assets/model-fa.zip
./gradlew assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

یا در Android Studio پروژه را باز کنید و Build > Generate Signed Bundle / APK را بزنید.

## نکات

- مدل تشخیص گفتار (model-fa.zip) به دلیل حجم بالا در این ریپو قرار داده نشده. از سورس اصلی کپی کنید.
- keystore.jks برای امضای انتشار در پروژه موجود است.
